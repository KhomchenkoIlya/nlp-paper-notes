# Modern Attention Methods (overview)

Цель: кратко зафиксировать современные идеи, которые расширяют базовый self-attention:
- эффективность на длинных контекстах (linear / kernel attention),
- управление потоком информации (gated attention),
- практические компромиссы (точность vs скорость/память).

Формат: **обзор + ссылки на toy-ноутбуки** из `notebooks/`.

---

## 1) Почему “обычный” attention дорогой

Vanilla self-attention для длины последовательности `n` строит матрицу попарных взаимодействий `n×n`:
- по памяти: `O(n^2)`
- по времени: `O(n^2 d)` (грубо)

Поэтому для длинных контекстов ищут приближения или разреженные схемы.

---

## 2) Linear attention (идея)

Цель: заменить вычисление `softmax(QK^T) V` так, чтобы уйти от явного `n×n`.

Классическая линия идей:
1) представить attention через **kernel trick** / feature map:
   `softmax(q_i^T k_j)` аппроксимируют как `φ(q_i)^T φ(k_j)` для некоторой `φ(·)`
2) тогда выражение можно перегруппировать:
   `A V ≈ (Φ(Q) (Φ(K)^T V)) / (Φ(Q) (Φ(K)^T 1))`
   и всё считается за `O(n d^2)` или `O(n d)` в toy-режиме (в зависимости от реализации)

Практический смысл: “платим” качеством аппроксимации, выигрываем скорость/память.

---

## 3) Kernel attention (интерпретация)

Kernel attention — это взгляд на внимание как на kernel similarity:
- обычный attention использует экспоненциальную “похожесть” (softmax над dot-product)
- kernel attention выбирает/аппроксимирует kernel `K(q,k)`

Важный момент: kernel должен быть **положительным** и желательно стабильно считаемым.
В toy-экспериментах можно брать простые `φ(x)` (например `ReLU(x)+1`) и смотреть, как меняются карты внимания.

---

## 4) Gated attention (идея “ворот”)

Gating добавляет управляемость: модель может “приглушать/усиливать” вклад внимания.
Схемы бывают разные, общий мотив:
- attention определяет *куда смотреть*,
- gate определяет *сколько информации пропускать*.

Toy-вариант: умножить `V` или уже готовый выход attention на `g(x)` (например sigmoid от линейной функции).

Зачем это нужно:
- стабилизация,
- селективность,
- контроль насыщения/шума.

## 6) Вывод (коротко)

Современные модификации attention в основном крутятся вокруг:
- **эффективности** (linear/kernel/sparse),
- **индуктивных байасов** (позиционные смещения, локальность),
- **управляемости** (gating).
